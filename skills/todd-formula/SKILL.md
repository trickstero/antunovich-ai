# Todd Formula — Exterior Visualization Prompt System

## Core Formula
```
Real photograph NOT a render NOT CGI, [subject], [site context],
[lighting/time of day], [landscape vocabulary],
[Canon EOS R5, 24mm, f/8, ISO 400, golden hour],
[material callouts: SW paint codes, cladding, stone],
hyperrealistic, photojournalism quality, architectural photography
--no render CGI illustration cartoon sketch painting watercolor
digital art 3D model blueprint technical drawing unrealistic
oversaturated HDR drone aerial fisheye distortion
```

## Model Selection
- **Nano Banana Pro:** Pure text-to-image. Extreme multi-layered prompts only.
- **NB2 (Gemini 3.1 Flash):** Image Grounding. 512px batch → upscale best. Default 95%.
- Thinking mode OFF by default. ON only for complex infographics.

## Active Project Vocabulary
- **Kingswood/Brekenwood (Idaho):** SW paint codes, pitched roofs, stone base, board-and-batten
- **Mixed-use retail:** Fieldstone retaining wall, Karl Foerster grass, lavender, black-eyed susans, muhly grass, exposed aggregate sidewalk

## Post-Processing Pipeline
Krea generate → Magnific (material reinterpretation) → Topaz 4K → Photoshop surgical fixes

## JJ Style (Watercolor)
Prominent linework, transparent tree canopies with sky gaps, visible branch structure, minimal leaf clusters, saturated greens (chartreuse/lime/emerald), warm purple-mauve shadows.

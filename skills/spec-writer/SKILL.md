# Spec Writer Skill

## MasterFormat Structure
```
SECTION XX XX XX — [TITLE]

PART 1 — GENERAL
  1.1 RELATED DOCUMENTS | 1.2 SUMMARY | 1.3 SUBMITTALS
  1.4 QUALITY ASSURANCE | 1.5 WARRANTY

PART 2 — PRODUCTS
  2.1 MANUFACTURERS | 2.2 MATERIALS | 2.3 FABRICATION

PART 3 — EXECUTION
  3.1 EXAMINATION | 3.2 PREPARATION | 3.3 INSTALLATION
  3.4 FIELD QUALITY CONTROL | 3.5 CLEANING
```

## Luxury Retail Protocol
- Armani/Prada/Brunello Cucinelli: brand-approved materials list required
- Custom millwork: shop drawing submittal requirement
- Bookmatched stone/onyx: quarry cert + mockup

Section 02 · Self-Learning Cycles

Four loops, compounding.

Daily · ~06:00

Passive Capture

X bookmarks scrape overnight → inbox/ → morning-synthesis triages → wiki ingest or discard. The bookmark is the capture event.

Weekly · Sundays

Firmware Upgrade

/firmware-upgrade reads 7 days of log + quality-log + candidates, drafts new AGENTS.md sections 2-4, presents diff before writing.

Per Session

Hard Rule Genesis

Failure → post-mortem in error-library → new Hard Rule → eval probe validates → the same failure mode never repeats.

Per Cowork Run

Specialist Promotion

Specialist learns pattern → _memory.md → if cross-applicable, promote to wiki/concepts/. Knowledge stops being siloed.

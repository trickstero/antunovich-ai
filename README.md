# Antunovich Associates — Claude Code AI Workspace

Production-grade Claude Code workspace for AI-assisted architectural practice.

## Quick Start
```bash
npm i -g @anthropic-ai/claude-code
cd antunovich-ai
npm run seed
claude
```

## Slash Commands
| Command | Purpose |
|---------|---------|
| `/rfi` | Draft RFI document |
| `/spec` | Write MasterFormat spec section |
| `/shpo` | SHPO preservation narrative |
| `/render` | Todd Formula Krea.ai prompt |
| `/review` | Code or document review |
| `/bootstrap` | Scaffold new project module |

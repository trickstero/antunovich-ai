Foundation — understanding the technology

What Is an AI Agent?

The Old Way — Chatbot

  • 1.You type a question into ChatGPT or Claude
  • 2.It answers from its training — no connection to your live files or software
  • 3.You copy the answer and do something with it manually
  • 4.Every task still requires a human to bridge the AI answer to the actual work product

→ Useful but passive. Knows nothing about your projects.

The New Way — Agent

  • 1.You give the AI a task: "Check Level 3 for ADA compliance and draft any required RFIs."
  • 2.The agent looks up IBC and ADA in a live code database, returns cited requirements
  • 3.It writes the RFI document in your firm's format
  • 4.It saves the file to your SharePoint project folder automatically
  • 5.You review, approve, send. 8 minutes total vs. 90 minutes manually.

→ Connected to your actual work. Does the task, not just the answer.

The BIM Analogy — how we already understand this

Think of an AI agent the way you think about Navisworks coordination: MEP, structural, and architectural models federated in one file — each consultant in their lane, coordination happening in shared space. An AI agent is a new kind of consultant that works across all your software simultaneously, at any hour, without billing for the time.

Foundation — the technical backbone

MCP: The Universal Connector

MCP — Model Context Protocol — is an open standard developed by Anthropic in 2024. It is to AI agents what USB-C is to devices: a universal port that lets any AI connect to any piece of software. Each MCP Server is a dedicated bridge between the AI and one specific tool.

AI Brain
Claude — reads the task, reasons, decides which tools to call
Understands project type, jurisdiction, and firm standards from the prompt. No setup per-task.
issues structured commands via MCP protocol to each server below
MCP Layer
MCP Servers — translators between AI and your software
Each server exposes one application to the AI. They all speak the same language Claude understands.
reads, writes, and executes actions inside each application
Your Tools
Outlook · SharePoint · Web (Code DBs) · Bluebeam
Your existing software — completely unchanged. MCP servers connect to them without replacing anything.

How it works — the Todd Formula & skill system

Skills: Encoding Judgment as Reusable Tools

What Is a Skill?

A skill is a precision-engineered prompt stored as a reusable instruction set — like a Revit template library but for AI. Built once, used by the whole team. The skill encodes professional judgment that took months to develop. A junior designer gets the result of that expertise immediately, without knowing how the prompt was built.

Todd Formula — Four Layers of the Skill
01
Reality anchor
"Real photograph NOT a render NOT CGI" — forces the AI away from every synthetic render artifact at the model level.
02
Camera specification
Canon EOS R5 · 24mm · f/8 · golden hour. Makes the AI think in photographic terms — not rendering terms. The difference is visible in every shadow and reflection.
03
Material language
Each surface in photographer's terms — texture, light behavior, weathering, depth — not architectural spec language. "Brushed oxidized zinc" not "metal panel".
04
Grouped negative prompts <2,000 chars
Systematically eliminates CGI glow, plastic surfaces, flat lighting, oversaturation — every telltale sign that this was generated, not photographed.

Workflow 1: ADA Compliance Check & RFI

1
Project Manager
"Check room 312 door clearances for ADA. Chicago AHJ. Draft an RFI if non-compliant and save it to the project folder."
PM types this directly into the Claude agent. No template, no form — plain English.
2
MCP → web-search
Agent queries IBC 2021 §1010.1.1 and ADA Standards §4.13 for maneuvering clearances. Also checks Chicago AHJ local amendments for any stricter requirements.
Returns: latch-side clearance 18" min · door swing clearance 60" · Chicago matches federal standard on this section
3
AI — Analysis
Compares code requirements to the room dimensions provided. Identifies: latch-side clearance at 14" — 4" short of the 18" ADA minimum. Flags as non-compliant.
4
AI — Writes RFI in Antunovich format
Drafts RFI-047 citing ADA §4.13 and IBC §1010.1.1. States the non-compliance, requests contractor to submit revised door rough opening or confirm field condition.
5
MCP → filesystem + email
Saves RFI-047.docx to /Project/CA/RFIs/. Drafts transmittal email to GC with RFI attached. PM reads, approves, sends.
✓ Works today — no custom development
90 min → 8 min
Manual: code lookup, clearance calc, RFI write-up, email draft. All automated — PM reviews output only.
Applies to every RFI
Any code question, any jurisdiction. IBC · ADA · NFPA 101 · Chicago AHJ · DC DCRA — all live, all cited.

# Onboarding — Antunovich AI Workspace

## Setup
1. `npm i -g @anthropic-ai/claude-code`
2. `cd antunovich-ai && npm run seed`
3. Add API keys to `.claude/settings.local.json`
4. Run `claude` — SessionStart hook fires

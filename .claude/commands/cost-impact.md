Analyze the cost and schedule impact of: $ARGUMENTS

Coordinate analysis across relevant project knowledge:
- Reference the spec-writer skill for affected specification sections and material costs
- Reference the procurement skill for subcontractor pricing context and active RFQs
- If this is a historic project (Uline Arena, Hotel Burnham, The Robey), flag preservation compliance implications via the shpo-narrative skill

## Deliverable Structure

**RECOMMENDATION:** One sentence — proceed, reject, or modify the proposed change.

**AFFECTED SCOPE:**
- Specification sections impacted (by MasterFormat number)
- Drawing sheets requiring revision (A/S/M/E/P-XXX)
- Trades and subcontractors affected

**COST ANALYSIS:**
- Direct material cost delta (per unit and total)
- Labor impact (installation hours, crew changes)
- Design fee impact (additional CA hours, revised drawings)
- Contingency recommendation (% of delta)

**SCHEDULE IMPACT:**
- Lead time change (weeks +/-)
- Submittal resubmission required? (yes/no + estimated review cycles)
- Construction sequence affected? (describe)

**VE ALTERNATIVES:**
- At least 2 alternative approaches with cost/quality tradeoffs
- Note any alternatives that compromise design intent

**RISK FACTORS:**
- Warranty implications
- Code compliance issues (IBC, ADA, energy code)
- Historic preservation conflicts (if applicable)

Format with specific dollar amounts and durations where possible. If data is unavailable, state assumptions clearly. Output follows Antunovich memo format — no bullet-point padding, bottom-line first.

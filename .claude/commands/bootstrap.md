# /bootstrap — Scaffold a New Project Module

## Usage
/bootstrap [project-name] [type: mixed-use|multi-family|student|retail|historic|hospitality]

## Creates
- docs/{rfis,specs,shpo,submittals}/[project-name]/
- src/components/[project-name]/
- Project entry in docs/projects.json
- .mcp.json Procore ID placeholder

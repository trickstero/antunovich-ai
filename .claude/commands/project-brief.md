Create a strategic project brief on: $ARGUMENTS

Coordinate across all relevant project knowledge and agents:
- Use the spec-writer skill for technical scope and material decisions
- Use the rfi-drafter skill for outstanding field questions and open items
- Use the shpo-narrative skill if the project involves historic fabric
- Use the procurement skill for budget status and subcontractor context

## Deliverable Structure

**EXECUTIVE SUMMARY**
- Key decision or status update (1–2 sentences)
- Critical path item requiring principal attention
- Next milestone and date

**PROJECT STATUS**
- Phase (SD / DD / CD / CA / closeout)
- Open RFIs (count, overdue count, critical items)
- Submittal status (approved / pending / rejected / resubmit)
- Budget position (on track / over / under, with delta)

**DESIGN DECISIONS PENDING**
- List each decision with options, cost implications, and recommended path
- Flag any decisions that affect base building vs. tenant scope
- Note brand-approval requirements for luxury retail projects

**PRESERVATION COMPLIANCE** (historic projects only)
- Standards compliance summary (cite specific Secretary of the Interior's Standards)
- SHPO submission status and review timeline
- Material match issues or substitution requests

**SUBCONSULTANT COORDINATION**
- MEP coordination items requiring architect response
- Structural issues affecting architectural scope
- Civil/landscape interface items

**RISK REGISTER**
- Top 3 risks ranked by probability × impact
- Mitigation actions underway
- Escalation items for principal

**NEXT STEPS**
- Action items with owners and dates
- Upcoming deadlines (submittals, reviews, permit milestones)

Output in Antunovich memo format. Lead with the decision, not the background. If writing for a specific principal, match their communication preference (e.g., Greg: concise bullet-driven; Mike: narrative with design rationale).

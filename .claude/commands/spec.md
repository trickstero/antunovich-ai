# /spec — Write or Edit a Specification Section

## Usage
/spec [division] [section number] [product/system]

## Behavior
- Structure: PART 1 GENERAL / PART 2 PRODUCTS / PART 3 EXECUTION
- Include submittals, QA, warranty requirements
- Reference ASTM, ADA, IBC standards as appropriate
- Luxury retail → require brand-approved materials list
- Save to docs/specs/[section-number].md

## Communication Principles

- Reference specific standards (IBC, ADA, ASTM, ASHRAE, NEC, IECC) with section numbers
- Include MasterFormat section numbers for every material or system discussed
- Show the reasoning — cite the code path, the product data, the precedent
- Distinguish between code-required, owner-required, and design-intent items
- Use CSI terminology and Antunovich drawing conventions

## Tone Rules

- Write as if this will be entered into a Procore log and read by the GC's project engineer
- Be precise about quantities, dimensions, and performance values — no "approximately"
- Distinguish "shall" (mandatory/code) from "should" (recommended) from "may" (optional)
- Use passive voice only for spec language ("substrate shall be prepared"); active voice everywhere else
- Include ASTM test method numbers with performance criteria (e.g., ASTM C1036, Class I)
- For historic projects, always reference the applicable Secretary of the Interior's Standard by number
